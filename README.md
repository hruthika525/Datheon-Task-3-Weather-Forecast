# SkyCast – Weather Forecast App

## About the Project
SkyCast is a responsive weather forecast web application built using HTML, CSS, and JavaScript. It uses the OpenWeatherMap API to provide real-time weather information for different cities.

## Features
- Search weather by city name
- Display current temperature
- Show humidity, wind speed, and weather conditions
- Display a 5-day weather forecast
- Loading and error messages
- Responsive design for different screen sizes

## Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Add your own OpenWeatherMap API key in `script.js`.
4. Open `index.html` using Live Server.

## API Key Setup
Replace the placeholder API key in `script.js` with your own OpenWeatherMap API key. Never upload your actual API key to GitHub.
